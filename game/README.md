# Compilation
To compile this project, execute `make <platform>`

For example
```bash
make linux
make windows
```

## AI assisted creation
Artificial intelligence was used in some code creation and image generation.

The main file affected by AI generated code is Source/Implementation/events.c. Mainly for debugging purposes
or repetitive code generation. The model used for this task is GPT-5.4mini accessed through duck.ai.

As for the images, only the frame of the cards have been generated, using the model MAI-image-2.6-flash accessed through Bing.
